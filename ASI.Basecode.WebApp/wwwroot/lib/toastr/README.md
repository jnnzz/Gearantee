# Toastr vendor assets

Existing Toastr dependency, downloaded from the cdnjs 2.1.4 distribution on November 2, 2026:

- https://cdnjs.cloudflare.com/ajax/libs/toastr.js/2.1.4/toastr.min.js
- https://cdnjs.cloudflare.com/ajax/libs/toastr.js/2.1.4/toastr.min.css
- License: https://github.com/CodeSeven/toastr/blob/master/LICENSE (included as LICENSE)

The application loads these local copies after jQuery. Shared appearance is defined in tailwind.src.css; do not edit the vendor files to change the theme.
